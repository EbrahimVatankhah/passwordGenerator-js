# 🔐 Password Generator

A high-end, responsive, and cryptographically secure password generator built with a focus on **Glassmorphism** design and superior user experience.

![Password Generator Preview]()

## ✨ Features

-   **🛡️ Secure Generation:** Uses the `Crypto.getRandomValues()` API for industry-standard randomness.
-   **💎 Glassmorphic UI:** Stunning frosted-glass effect with smooth Tailwind CSS animations.
-   **🚫 Ambiguous Filter:** Option to exclude confusing characters like `i, l, 1, L, o, 0, O`.
-   **📊 Strength Meter:** Real-time visual feedback on password complexity.
-   **📜 History Log:** Remembers your last 3 generated passwords so you never lose a good one.
-   **⌨️ Hotkeys:** Press `Spacebar` to instantly generate a new password.
-   **📱 Fully Responsive:** Optimized for mobile, tablet, and desktop screens.

## 🛠️ Built With

* **HTML5** - Semantic structure.
* **Tailwind CSS** - Modern styling and layout.
* **Vanilla JavaScript** - Clean, library-free logic.
* **Google Fonts** - Plus Jakarta Sans & JetBrains Mono for maximum legibility.
